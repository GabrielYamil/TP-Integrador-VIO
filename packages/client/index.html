Inicio rápido

pnpm install
pnpm cert:setup   # consola elevada
pnpm dev

En el celular, instalá certs/rootCA.pem como CA de usuario y abrí la URL HTTPS de esta PC en el puerto 5173. Para la versión compilada: pnpm build && pnpm start (puerto 8443).

Sin celular, generá telemetría con pnpm sim -- --drift y conectá Foxglove Studio a ws://IP_DE_LA_PC:8765.

Qué cubre la Fase 0 + 1 + 2 + 3

  • Monorepo pnpm, TypeScript estricto, ESLint y Vitest.
  • Matemática SE(3), conversiones WebXR/OpenCV/ROS y tests sintéticos.

  • Relay /ingest, servidor Foxglove y simulador de trayectorias.
  • Cliente /ar.html con sesión immersive-ar, overlay y pose cruda a ~30 Hz con reconexión automática.

Relay y Foxglove (Fase 2)

Ingesta: verificando… Foxglove: verificando…

Foxglove Studio se conecta a ws://IP_DE_LA_PC:8765. Canales: /tf, /pose/raw, /pose/corrected, /markers y /metrics.

El cliente AR envía la pose cruda desde /ar.html. El relay valida cada mensaje con zod; los inválidos se descartan y se registran en la consola del servidor.

Verificación manual pendiente

  • Certificado aceptado por Chrome Android sin advertencias.
  • La sesión AR inicia y entrega pose de tracking.
  • La pose de /ar.html se mueve en Foxglove y los ejes son correctos.
  • camera-access entrega textura de cámara en el celular real.
  • Foxglove Studio muestra los canales, el árbol de TF y las trayectorias.
  • El emulador de Android Studio no implementa WebXR: no sirve para esto.
