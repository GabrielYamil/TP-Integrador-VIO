Inicio rápido

pnpm install
pnpm cert:setup   # consola elevada
pnpm dev

En el celular, instalá certs/rootCA.pem como CA de usuario y abrí la URL HTTPS de esta PC en el puerto 5173. Para la versión compilada: pnpm build && pnpm start (puerto 8443).

Qué cubre la Fase 0 + 1
